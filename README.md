# celalcankaya.github.io

Personal developer page for CCK Studio (Celal Can Kaya): hosts `app-ads.txt` for AdMob, plus a
privacy policy and terms of use for each published app.

- `app-ads.txt` - required for AdMob ad-serving authorization, do not move or rename.
- `index.html` - landing page linking to each app's legal docs.
- `apps/<app-name>/privacy-policy.html`, `apps/<app-name>/terms-of-use.html` - per-app legal docs
  (bilingual EN/TR, shared theme in `assets/`). Add a new `apps/<app-name>/` folder for each new
  app published under CCK Studio.

You can check out my [Play Store profile](https://play.google.com/store/apps/dev?id=6186542380897301429).
